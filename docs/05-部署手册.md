# 部署手册 · ESOP 发布系统 v1.10.0

> 面向：把服务端和 5 台终端装到线上的人。
> 目标：**从拿到 exe 到屏上出正确内容，一台不超过 5 分钟**（A6 实测 10.3 秒首装、6.96 秒开机）。

---

## 0. 服务端先装在哪（只要一台）

服务端是**桌面程序**：双击一个 exe，服务和界面一起起来。**不装 Node.js、不用管理员权限、不用浏览器。**

| 文件 | 说明 | 大小 / 校验 |
|---|---|---|
| `server-gui/dist/ESOP-Server.exe` | **服务端整包（v1.8.0）**，单文件免安装 | 92.8 MB<br>`sha256: a6792bafe6f9e4281e2485b5495b4d4eeb6b161b136799304356959a0165d38a` |
| `terminal/dist/ESOP-Client.exe` | 终端接收端（v1.6.0），**单文件免安装**，5 台各一份 | 69.7 MB<br>`sha256: 333630b2975be1dbf7e588d2671bc55f7a917592473af2532bf8cac6fb40f55b` |
| `docs/a7-检验卡-1280x720.png` | A7 可读性检验卡，现场用 | 65 KB |

### 服务端装机三步

1. 把 `ESOP-Server.exe` 放到 `D:\ESOP-Server\`（**路径用纯英文、不要空格**）。
2. **双击它**。窗口打开就是管理界面，同时 `D:\ESOP-Server\data\` 目录自动建好。
3. 点顶栏的 **「系统」** 按钮，里面有**终端装机要填的服务端地址**（形如 `http://192.168.x.x:8092`），
   点「复制」存下来，装 5 台终端时逐台粘贴。**不要填 127.0.0.1**，那是服务端自己看到的地址。

顺手做两件事：

- **开机自启**：在「系统」面板里打开开关（或右键托盘图标勾选）。只写当前用户，不需要管理员。
  自启后静默进托盘、不弹窗口 —— 这是常驻服务的正常表现。
- **防火墙**：第一次启动 Windows 会弹「是否允许访问网络」，勾「专用网络」允许。
  没弹或被拒了，用管理员 cmd 执行一次：
  ```
  netsh advfirewall firewall add rule name="ESOP-Server 8092" dir=in action=allow protocol=TCP localport=8092
  ```

服务端的数据全在 exe 同级的 `data\`（数据库 + 工程部上传的图片视频 + `server.log` 日志）。
**备份就备份这个文件夹**；换机器时连整个文件夹一起拷过去。

### 关窗口 ≠ 关服务（一定要知道）

双击 exe 后，右下角托盘会多一个图标。

| 你做的操作 | 会发生什么 |
|---|---|
| 点窗口右上角 **X** | **窗口消失，服务继续跑**，缩到托盘里，5 台终端照常工作 |
| 双击托盘图标 / 右键→显示管理界面 | 窗口重新出现 |
| 右键托盘 → **退出服务端** | 真的停止，5 台终端全部掉线（有终端在线时会二次确认） |

这是刻意设计：服务端是产线的核心，误关一次窗口就断线，代价太大。
所以**找不到窗口时去托盘找，不要重复双击 exe**（重复双击只会把已有窗口唤回来，不会开出第二个服务）。

### 出问题了先看日志

`D:\ESOP-Server\data\server.log` 双击就能用记事本打开（已带 UTF-8 BOM，不会乱码）。
「系统」面板里有「定位」按钮直接跳过去。超过 2 MB 自动改名成 `server.log.1`。

<details>
<summary>无图形界面 / 远程桌面场景：改用绿色免安装包</summary>

服务端如果是远程桌面、或者不希望桌面上出现窗口，用绿色包：
`release/online-vwi-server-1.4.0-win-x64.zip` 解压到 `D:\ESOP-Server`，双击 `启动服务端.bat`，
再用浏览器开 `http://服务器IP:8092/`。附带 `停止服务端.bat`、`设置开机自启.bat`、`取消开机自启.bat`；

**两种形态功能完全一致**（共用 `src/server-core.js`），只是入口不同：桌面版是「服务+界面一个 exe」，
绿色包是「服务脚本 + 浏览器访问」。

| 文件 | 说明 | 大小 / 校验 |

| `server-gui/dist/ESOP-Server.exe` | **服务端桌面程序（现场用这个，v1.9.0）** | 92.8 MB |

> exe 每次启动会自解压到 `%TEMP%\esop-client` 再运行，所以**第一次启动慢 2–3 秒**，之后就稳定在 7 秒左右。

### 从旧版升级（服务端 1.5.0 / 终端 1.6.0 → 本版）

这一版把产品名从「在线VWI」改成 **ESOP**，exe 固定叫 `ESOP-Server.exe` / `ESOP-Client.exe`。
**代码会自动迁移，不用重装**，但下面几件事必须知道：

| 项 | 旧 | 新 | 要不要人工处理 |
|---|---|---|---|
| 服务端目录 | `D:\VWI-Server\` | `D:\ESOP-Server\` | 不用。老机器留在原目录照样跑，文档按新目录写；想统一就把**整个文件夹**改名，`data\` 一起走，别只搬 exe |
| 终端目录 | `C:\VWI\` | `C:\ESOP\` | 同上。**开机自启项写的是 exe 绝对路径**，目录改了要重新打开一次「开机自启」 |
| 终端配置目录 | `%LOCALAPPDATA%\online-vwi-terminal\` | `%LOCALAPPDATA%\esop-client\` | **不用**。首次启动自动迁移（含 content 缓存），地址与工序全部保留；迁移结果记在 `logs\terminal.log` 的 `[config]` 行 |
| 开机自启项名 | `com.frank.online-vwi-terminal` | `com.frank.esop-client` | 旧注册表项不会自动清。建议升级后把「开机自启」关一次再打开，并确认 `HKCU\...\Run` 里没有残留的 `online-vwi` 项 |
| 防火墙规则名 | `VWI-Server 8092` | `ESOP-Server 8092` | 只是名字，旧规则继续有效；重命名可选 |
| 服务端数据库 | `data\vwi.db` | **仍然是 `vwi.db`** | 故意不改：这个文件名用户看不到，改它只多一次数据迁移的风险 |
| 终端日志/缓存 | `%LOCALAPPDATA%\online-vwi-terminal\logs\` | `%LOCALAPPDATA%\esop-client\logs\` | 跟着配置目录一起迁 |

**回滚**：换回旧 exe 即可。服务端库只新增过表，旧版读它会忽略不认识的表；
终端若已迁移到 `esop-client`，回滚前把该目录改名回 `online-vwi-terminal`，否则旧版会当成"没装过"、弹装机向导。

## 2. 装机五步（单台，实测 10.3 秒）

### ① 把 exe 放到固定目录

```
C:\ESOP\ESOP-Client.exe
```

**不要**放在这几个地方：桌面、下载文件夹、OneDrive / 网络盘、`%TEMP%`。
前两个会被清理工具当垃圾删掉，后两个会让开机自启在断网时找不到文件。

### ② 显示器设成 1280×1024、缩放 100%

播放页是按 **1280×1024 设计画布** 做的，这个分辨率下是 1:1 像素，最清晰。
缩放设成 125% 会让整个界面按比例缩小，字变小、A7 可读性打折。

### ③ 关掉会打断播放的系统行为

| 项 | 设为 | 原因 |
|---|---|---|
| 屏幕保护 | 关 | 屏保会盖住画面 |
| 睡眠 / 休眠 | 永不 | 睡眠后不响应切换 |
| 显示超时关闭 | 永不 | 同上 |
| Windows 自动更新重启 | 设活动时间 | 半夜重启后终端会自启，但会闪一下 |

### ④ 双击 exe，走装机向导

1. 填服务器地址：`http://<服务器IP>:8092`，点 **检测**
2. 选这台屏属于哪条**线体**（如 `一线`）。只有一条线体时自动选中，不用点
3. 出现工序后，选这台屏对应的那道（如 `OP10 上料`）
4. 点 **保存并开始**

保存后自动进入全屏播放，顶栏出现 `型号 | 工序 | ● 在线` 才算成功。

### ⑤ 记下这台屏是哪道工序

5 台机器只有这一步不同。**同一道工序不要装两台**——一台屏 = 一道工序，这是本项目一期的明确取舍（没有工位概念）。

## 3. 批量部署（5 台一起）

不想在 5 台机器上各点一遍向导，就用配置外置法：

1. 在 exe 同级目录放一个 `config.json`：

```json
{
  "line": "L1",
  "op": "OP10",
  "server": "http://192.168.1.100:8092",
  "kiosk": true,
  "autoStart": true,
  "pollFallbackMs": 30000,
  "allowDevTools": false
}
```

2. 把这个 `C:\ESOP\` 整个目录拷到 5 台机器；
3. 每台只改 `op` 那一行（`OP10` / `OP20` / `OP30` / `OP40` / `OP50`）；
   `line` 是多产线时才需要区分（如一线 `L1`、二线 `L2`），留空表示"跟随服务端当前启用的线体"；
4. 双击 exe，**不再弹向导**，直接进播放。

> 配置优先级：**exe 同级的 `config.json` > `%LOCALAPPDATA%\esop-client\config.json`（向导写的）**。
> 所以要临时改配置，改 exe 旁边那份再重启最省事。
> portable 单文件包运行时程序在临时目录里跑，`exe 同级`是靠 `PORTABLE_EXECUTABLE_DIR` 定位的，已处理（v1.3.0）。

## 4. 日常运维

### 换型（工程部在管理端点一下）

管理端 `http://<服务器>:8092` → 底部右下角选新型号 → 切换。换型作用于**当前查看的那条线体**。

### 换线体（今天跑另一条线）

顶栏下面那排线体 → 点 **启用线体** → 选今天要跑的那条 → 确认。

- 同一时刻只有一条线体在跑，换线不动另一条线已配好的内容（明天换回来内容还在）。
- 正在看一条没启用的线体时，页面上方会出黄条提示"终端目前不会读这条线的内容"，
  点黄条上的按钮就能直接设成启用。
- 新建线体会自动带 5 道标准工序，工序名可以改；**有播放内容的线体不允许删除**。
5 台屏**先各自下载、全部就绪后才一起翻**，切换瞬间不黑屏、不混批，实测 0.9 秒内完成。

### 配置库（规定"这个产品该交什么"）

管理端左栏 → **配置库**。它和「作业内容」是两套东西，别混：

- 配置库 = **应该有什么**（模板）：这个产品在哪几条线做、几道工序、每道要交几张图/几段视频/几份 PDF。
- 线体内容 = **实际有什么**：真正下发给终端的那套东西。

三个动作：

1. **应用到线体…** —— 把选中线体的工序数量/名称对齐成配置里的。
   默认**不删**配置外的工序；勾了"顺便删"也只删**没有内容**的，有播放内容的永远保留。
2. **校验现状** —— 只读检查。选线体 + 机种，出 `4/5 道工序达标` 和每道缺什么。
3. 在「线体内容」里，矩阵表头会显示匹配到的要求（`图≥1`）和 ✓/✕；
   打开清单抽屉时，顶部会写清这道工序的要求，不符合的项直接标红并说明原因。

**首次使用**：系统自带一份「标准 ESOP 工艺模板」（5 道工序、每道至少 1 张 ≥1280×720 的图）。
按实际产品改，或者「+ 新建配置」另起一份。编码建议带上机种号（如 `P-X300`），
矩阵会自动匹配上，不用手工指定。

> 改配置**不会**影响正在播的内容。模板被改坏最多是校验不通过，不会让屏黑掉。

### 看终端状态（「终端监控」页）

左栏 → **终端监控**，每台屏一行，字段横排不截断：

| 字段 | 含义 |
|---|---|
| IP 地址 / 分辨率 / 版本 | 终端上报的本机参数 |
| 剩余磁盘 | 终端磁盘剩余空间，低于 1 GB 要留意 |
| 下载进度条 + `X300 3/12 项` | 这套内容下到第几项；转绿 + 「已就绪」表示已举手可翻 |
| 状态 | 在线/下载中、在线已就绪、已离线 N 分钟、从未上线 |

「作业内容」页右侧也有一栏**精简就绪条**（只写"哪几台还没就绪"），
换型前扫一眼就够；要查 IP、分辨率、磁盘这些细节就切到「终端监控」页。

- 「从未上线」= 这台屏从来没连过服务器，先查是否装了、IP 通不通。
- 「已离线 N 分钟」= 连过，现在断了（关机/网线掉了）。
- 参数显示「—」= 那台终端的版本还低于 1.6.0，升级后就能看到。

### 换线（今天跑哪条线）

左栏 → **线体设置**，一张表格列出所有线体：

| 列 | 说明 |
|---|---|
| 启用（勾选框） | 打勾 = 这条线今天在跑，终端读它的内容 |
| 编码 / 名称 | 编码是终端装机时要填的标识，一般不改 |
| 工序数 / 内容覆盖 | 这条线有几道工序、配齐了几套 |
| 当前型号 / 在线 | 这条线正在播什么、有几台屏在线 |
| 操作 | 查看、改名、上下排序、删除 |

**同一时刻只允许一条线体启用**（服务端保证）。停用中若没有别的线顶上会先弹确认框，
因为那样终端会连不上服务端、屏上内容停住。

> 顶部的**上下文条**（当前线体胶囊）只用来**切换"在看哪条线"**，不改变启用状态 ——
> 浏览内容时误触勾选框会让整线停产，所以启停一律到「线体设置」页做。
> 启用的那条在线体设置表和上下文条里都**恒排最前**，绿点标记"今天在跑"。

### 改内容（改错图、补注意事项）

管在理端改完清单**保存即可**，终端会在 0.3 秒内自动重下并刷新——**不需要换型，也不需要重启终端**。
（v1.3.0 新增：服务端 `contentRev` + 终端清单指纹比对。改的是别的工序时，本机不会闪屏。）

### 托盘

右下角托盘图标右键：

| 菜单 | 用途 |
|---|---|
| 重新加载画面 | 画面异常时先点这个 |
| 重新同步内容 | 怀疑内容不对时点 |
| 打开内容目录 | 看本地缓存了什么 |
| 打开日志 | 排障第一现场 |
| 更改设置… | 改服务器地址 / 工序 |
| 退出 | 正常退出（生产上一般不用） |

### 退出与逃生

- 窗口关不掉（kiosk + 关窗拦截）是设计如此；
- **`Ctrl + Alt + Shift + Q`** 强制退出，这是唯一的逃生门，请写在工位交接卡上；
- `Alt+F4` / `Ctrl+W` / `F11` / `F5` 全部被拦截。

### 开机自启

保存配置后自动写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
（项名 `com.frank.esop-client`，值为 exe 路径 + `--autostart`）。
换机器、换目录后要重新保存一次配置，否则注册表里还是旧路径。

## 6. 故障排查

| 现象 | 大概率原因 | 处理 |
|---|---|---|
| 双击没反应 | 已经在跑（单实例锁） | 看托盘；或 `Ctrl+Alt+Shift+Q` 退掉再启动 |
| 顶栏红底白字「内容未就绪 · 请勿作业」 | 本机没下完内容，服务端已经超时强翻 | 别动，等它自己补齐；一直不变看日志确认网络 |
| 顶栏灰点「离线」 | 连不上服务器 | `ping 服务器IP`、确认 8092 端口、确认服务端在跑 |
| 橙字「内容不全 0 项」 | 这个型号这道工序没配内容 | 管理端补内容，保存后自动生效 |
| 画面比例不对 / 两边黑边 | 这不是故障 | 指导书不是 16:9 时会留黑边，**刻意不裁图** |
| 字太小看不清 | 显示器缩放不是 100% | 改回 100%，见第 2 节 ② |
| 一直卡在「准备中」 | 网络太慢或超大视频 | 看日志下载进度；5 分钟未完成会转红字告警 |
| 开机没自启 | 移动过 exe 或换了目录 | 托盘 → 更改设置 → 再保存一次 |

| A10 | 掉队可见 | 限速一台，等 5 分钟 | ✅ 超时红字「内容未就绪」 |

## 8. 指导书制作规范（给工程部）

现场 19 寸屏、1 米观看距离，光学上 2 mm 特征有 6.9 倍余量，但**这几个约束决定余量会不会被吃掉**：

| 项 | 要求 | 原因 |
|---|---|---|
| 画幅 | **1280 × 720（16:9）** | 内容区是 1280×816，16:9 图正好 1280×720，**1:1 零缩放** |
| 不要用 1920×1080 | 会被压到 0.667x | 2 mm 细节只剩 4.5 个像素采样，等于白做高清 |
| 不要用 4:3（如 1280×1024） | 会被压到 1020×816 | 2 mm 特征缩水到 5.4 px |
| 视频 | 1280×720，H.264，≤3 Mbps | 5 台并发下载要在 5 分钟内完成（单套建议 ≤120MB） |
| 关键细节 | 不小于 7 px（≈2 mm） | 这是 A7 的判据线 |
| 字体 | 正文 ≥24 px | 48 px 约等于 1 cm 高的字，1 m 外很轻松 |

> 一句话：**按 1280×720 出图，别往上传 1080P 甚至 4K**，上传大图不会更清楚，只会更慢。

**v1.6.0 起的两点变化**（内容制作时注意）：

1. **PDF 可以直接传**。服务端会按页渲染成 PNG（A4 竖版输出 1086×1536，约 26 KB/页），
   一页一条记录，按顺序进播放队列。适合直接丢工程部现有的 PDF 指导书，不必手工截图。
   上限 200 页/份；加密 PDF 会报错。要挑页请先在源文件里删好再传。
2. **图片显示方式每项可调**（清单里选）：`适应·不裁`（默认）/ `铺满·裁边` / `缩放 50%–200%`。
   如果 16:9 素材投到 5:4 屏上觉得黑边太大，可以选"铺满"，但**会裁掉两边内容**，
   指导书上的尺寸标注别贴着边缘放。视频时长不再限 60 秒，
   界面会按实际字节数算"预计换型耗时"给你看。

## 9. 已知限制（一期明确不做）

- 没有工位/终端档案管理：一台屏 = 一道工序，只配 `op`
- 不能分屏各自设型号：换型全网统一
- 不保留历史型号内容：切完即删，想回看要重新下载
- 没有权限和操作审计：谁都能换型（记录只在日志里）
- 清单一改就整批重下（约 27 MB），不是增量
- exe 未做代码签名：Windows 首次运行可能提示"未知发布者"，选"仍要运行"即可
