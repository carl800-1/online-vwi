# 5.0.1 重构方案：只留「选机种 → 传内容 → 推到屏」

> 2026-11-17 · 基于 5.0.0。上一稿还留了柱状图和产量录入，本稿按「与功能无关的先精简」全部砍掉。
> 判断标准只有一条：**这一步是不是在把视频 / VWI 送到屏上？** 不是，就不进 5.0.1。

## 一、一句话定位

这台主机只做三件事：**给机种+工序配内容 → 点一下推到线上屏 → 看屏在不在、播的对不对。**

除此之外的一切（产量、工时、效率、线平衡、换型协商、指派下发、Excel 五页、文件体检）都不是这个系统的活。

## 二、砍完只剩什么

导航 **8 项 → 4 项**（桌面版多一个「系统」）：

```
作业内容     运行产线 + 推送面板（选线 → 选机种 → 推送）
媒体库       选机种 → 选工序 → 传视频 / PDF / 图片，设播放内容与播放方式
机种设置     工序清单（工序码 / 名称），导入 Excel
终端监控     哪些屏在线、报的哪道工序、播什么（同工序冲突红标）
系统         托盘、8092 端口、数据目录、线体清单（极简）
```

## 三、删除清单（本轮真正要动手的）

### ① 页面 / 卡片

| 删 | 理由 |
|---|---|
| **生产概况卡 + 柱状图**（`renderProd` / `.pcard` / `.pchart`） | 你已确认砍。它回答的是「今天做了多少」，跟发布内容无关 |
| **生产输入页**（`view-prod`，约 90 行 HTML + 400 行 JS） | 唯一消费者就是柱状图；柱状图没了，产量录入就没人看 |
| **文件查询页**（`view-files`） | 全库搜索 / 规格体检 / 手工清理，日常不用；「清理未引用」收成媒体库一个按钮 |
| **产线概览卡**（`bsum`） | 跟「运行产线」重复：一个数几条线在跑，一个直接列出是哪几条 |
| **操作说明卡**（`bhelp`） | 里面写的是排产 / 换型 / 换型中 / 放弃切换 —— 全是本版要删的机制 |
| **线体设置页**（`view-lines`） | 压成「系统」里一块极简清单：名称 / 编码 / 状态 / 在线，能改名能改状态就够 |

### ② 机制

| 删 | 现状 | 为什么 |
|---|---|---|
| **换型两段式** | `switchTo` → `prepare` → 屏举手 `/api/ready` → 集齐才 `activate`，5 分钟强切 | 5.0.0 的「推送」已经直切（落库即生效），这套协商现场不会再点；留着屏端多一条分支、界面多一堆"准备中" |
| **排产下一个机种** | `next_model_id` + 「+ 排产下一个」+ 「换型」按钮 | 推送面板的多选机种就是候选池，点哪个推哪个；"先排后换"这层多余 |
| **指派下发** | `client_bind` + 四态握手 + `applyAssignment()` 改写屏 ctx + 终端 `applyAssign()` 改写 config.json | 屏上填的工序号是装机一次性动作，填错到屏前改更快；保留心跳台账 + 同工序冲突红标即可 |
| **工时与产能** | `model.std_rate` → 效率；`process.cycle_sec` → 瓶颈 / 线平衡率 | 这些数只在生产概况里出现，概况砍了就一个都不被用到 |
| **线体 Excel 五页 / 机种导出** | `linesSheet.js`、`export.js` | 单机单线不需要批量维护线体；机种导入保留 |

### ③ 接口与字段（停用，不删列）

- 下线路由：`/api/prod/*`、`/api/ready`、`/api/board/switch`、`/api/switch/cancel`、`/api/board/next`、`/api/lines/export|template|import`
- 保留列不迁移：`prod_input.*`（整表停用）、`line_state.pending_*`、`client_bind`、`process.cycle_sec`、`model.std_rate`
- **老库直接启动**，不写迁移脚本，不搬数据

## 四、原样保留（一行都不动）

- **内容模型**：机种 × 工序、媒体落盘目录、PDF 拆页、sha256 校验、播放内容三类勾选
- **分发机制**：`contentRev` + 长轮询 + 屏主动来拉 + 指纹变了才翻转（这是实测 0.1 秒到屏的那套）
- **直切推送**：`POST /api/board/current`（`setCurrentModel`，落库即生效、`seq+1` 唤醒）
- **屏台账**：`client` 心跳表（IP / 机名 / 工序 / 版本 / 在线）
- **播放器**：等待页各种状态、空清单不黑屏、1.8.3 修的内容暂停清屏
