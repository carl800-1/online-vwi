机种

工序设定

—
工序码 名称 做什么 播放方式 播放内容 内容
工序码由新建机种时定下（OP1、OP2…），终端上的工序号要和它一致（?op=OP1）， 所以这里只读。名称 / 做什么 / 播放方式 / 播放内容点一下就能改，离开这一格自动保存。 「做什么」写作业要点，会显示在终端顶栏；往工序里放图片 / PDF / 视频请去「媒体库」。
播放方式和播放内容只在这里设（媒体库里不再重复设一遍）： 前者管循环还是播一遍停，后者管这块屏放哪几类（图片 / PDF / 视频），至少要留一类。
哪块屏播哪道工序，在屏自己的设置里填线号和工序号 —— 服务端只负责记录， 打开「终端监控」就能看到谁连上来了。
